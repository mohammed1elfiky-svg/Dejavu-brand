# تجربة النظام بشكل حي

## الطريقة 1 — من المتصفح مباشرة (GitHub Codespaces) ⭐ الأسهل

لا تحتاج تثبيت أي شيء على جهازك.

1. افتح المستودع على GitHub واختر الفرع `claude/accounting-system-setup-u5okpy`.
2. اضغط الزر الأخضر **Code** ← تبويب **Codespaces** ← **Create codespace on claude/accounting-system-setup-u5okpy**.
3. انتظر 3–5 دقائق في أول مرة (يتم تلقائياً: تثبيت المكتبات، إنشاء قاعدة البيانات، تحميل البيانات التجريبية).
4. سيبدأ الخادم وحده في نافذة الطرفية، وتفتح صفحة **Swagger** في تبويب جديد.
   - إذا لم تفتح: تبويب **PORTS** بالأسفل ← المنفذ `3000` ← أيقونة الكرة الأرضية 🌐.

> Codespaces مجاني حتى 60 ساعة شهرياً للحسابات الشخصية. أوقفه من github.com/codespaces عند الانتهاء.

## الطريقة 2 — على جهازك بأمر واحد (Docker)

يتطلب [Docker Desktop](https://www.docker.com/products/docker-desktop/) فقط:

```bash
git clone https://github.com/mohammed1elfiky-svg/Dejavu-brand.git
cd Dejavu-brand
git checkout claude/accounting-system-setup-u5okpy
docker compose up --build
```

ثم افتح: **http://localhost:3000** (ستتحول تلقائياً إلى صفحة Swagger).
لإعادة البيانات من الصفر: `docker compose down -v` ثم `docker compose up`.

## الطريقة 3 — للمطورين (Node.js 22)

```bash
docker compose up -d postgres
cd backend && cp .env.example .env && npm install
npm run db:deploy && npm run db:seed && npm run db:seed:demo
npm run start:dev
```

## ماذا ستجد في البيانات التجريبية

- 8 منتجات في 4 تصنيفات (فساتين، بلوزات، بناطيل، إكسسوارات) بمقاسات وألوان، ومخزون افتتاحي.
- كوبون `WELCOME10` (خصم 10% بحد أقصى 300 جنيه) ومناطق شحن لـ 5 محافظات.
- قيد إيداع رأس مال 200,000 وقيد إيجار 15,000.
- **مورد** (مصنع النيل للملابس) وأمرا شراء: الأول مستلم بالكامل ومدفوع جزئياً، والثاني مستلم جزئياً.
- **4 مصروفات**: إنترنت وإعلانات (مدفوعة)، كهرباء (معتمدة وغير مدفوعة)، تغليف (مسودة تنتظر الاعتماد).
- **مرتجعان**: إيشارب مستلم ومردود ثمنه نقداً، وفستان بانتظار المراجعة.
- **تسوية Bosta**: سلّمت مبلغ الطلب 000001 مخصوماً منه عمولة 35 جنيه.
- **جرد فعلي** اكتشف نقص تيشيرت واحد.
- 5 طلبات في حالات مختلفة:

| الطلب | الحالة | ما توضّحه |
|---|---|---|
| SO-…-000001 | تم التسليم، دفع عند الاستلام، بكوبون | قيد المبيعات + التكلفة + تحويل المستحق لشركة الشحن |
| SO-…-000002 | تم الشحن، مدفوع بالبطاقة مسبقاً | الدفعة المقدمة ثم تسويتها مع الفاتورة |
| SO-…-000003 | بانتظار التأكيد | المخزون محجوز ولا يوجد قيد بعد |
| SO-…-000004 | قيد التجهيز | — |
| SO-…-000005 | ملغي ومسترد | قيد الدفع ثم قيد الاسترداد |

## جولة مقترحة في Swagger (10 دقائق)

**1. الدخول**
- افتح **Auth ← POST /auth/staff/login** ← **Try it out**، واكتب:
  `{ "email": "admin@dejavu.local", "password": "ChangeMe!2026" }` ← **Execute**.
- انسخ قيمة `accessToken` من الرد، واضغط زر **Authorize** 🔓 أعلى الصفحة والصقها. سيبقى الدخول محفوظاً حتى لو حدّثت الصفحة.

**2. شاهد الطلبات وقيودها**
- `GET /admin/orders` ← انسخ `id` أول طلب.
- `GET /admin/orders/{id}` ← انزل إلى `journalEntries`: سترى القيود التي ولّدها الطلب تلقائياً، و`profit` (الإيراد والتكلفة ومجمل الربح).

**3. التقارير المالية**
- `GET /admin/reports/trial-balance` ← ميزان المراجعة، و`totals.balanced` يجب أن تكون `true`.
- `GET /admin/accounts` ← انسخ `id` حساب المخزون (1120) ← `GET /admin/accounts/{id}/ledger` لكشف الحساب.

**4. نفّذ عملية بنفسك**
- `POST /admin/orders/{id}/status` على الطلب 000003 بـ `{ "status": "CONFIRMED" }` ثم `{ "status": "SHIPPED" }`.
- ارجع لميزان المراجعة: ستزيد المبيعات وتكلفة البضاعة وينقص المخزون، ويبقى الميزان متوازناً.

**5. جرّب كعميل**
- `POST /auth/customer/login` بـ `{ "phone": "01000000003", "password": "Demo!2026" }` ← ضع التوكن في **Authorize** بدل توكن المدير.
- `GET /store/products` ← اختر `id` أحد المقاسات من `variants`.
- `POST /store/cart/items` ← `PUT /store/cart/coupon` بـ `WELCOME10` ← `GET /store/me/addresses` لأخذ `id` العنوان.
- `GET /store/cart?addressId=...` ← ستظهر الأسعار والضريبة والشحن والخصم.
- `POST /store/orders` بـ `{ "addressId": "...", "paymentMethod": "CASH_ON_DELIVERY" }`.

**6. المشتريات والمصروفات والمرتجعات**
- `GET /admin/purchase-orders` ← افتح الأمر الثاني (مستلم جزئياً) ← `POST /admin/purchase-orders/{id}/receive` لاستلام الباقي.
- `GET /admin/suppliers` ← رصيد المورد، ثم `POST /admin/supplier-payments` لسداد جزء منه.
- `GET /admin/expenses?status=DRAFT` ← `POST /admin/expenses/{id}/approve` (أرسل `paidFromAccountId` إن دُفع فوراً).
- `GET /admin/returns?status=REQUESTED` ← `approve` ← `receive` ← `refund`.
- في كل خطوة: افتح المستند (أو `GET /admin/journal-entries`) لترى القيد الذي وُلّد.

**7. التقارير المالية**
- `GET /admin/reports/dashboard` ← لوحة المؤشرات (مبيعات اليوم، النقدية، المستحقات، الالتزامات، أرباح الشهر).
- `GET /admin/reports/income-statement` ← قائمة الدخل (الإيرادات، التكلفة، مجمل الربح، المصروفات، صافي الربح).
- `GET /admin/reports/balance-sheet` ← الميزانية، و`balanced` يجب أن تكون `true`.
- `GET /admin/reports/sales?groupBy=product` ← المبيعات والربح لكل منتج.

**8. جرّب الصلاحيات**
- ادخل بحساب `store@dejavu.local` وحاول `GET /admin/orders`: ستحصل على 403 مع اسم الصلاحية الناقصة.

> **نصيحة:** يمكنك أيضاً استيراد الـ API كاملاً في **Postman** أو **Insomnia** من الرابط `/docs-json`.

## تجربة تطبيق العملاء (أندرويد)

1. حمّل الـ APK من تبويب **Actions** في GitHub ← آخر تشغيل **Android** ← **Artifacts** ← `dejavu-customer-debug-apk`.
2. ثبّته على موبايل أندرويد (8.0 فأحدث) أو على محاكي Android Studio.
3. شغّل الخادم بإحدى الطرق السابقة، ثم من التطبيق: **حسابي ← الخادم**:
   - محاكي على نفس الجهاز مع Docker أو Node: `http://10.0.2.2:3000`
   - Codespaces: من تبويب **PORTS** اجعل المنفذ 3000 **Public**، ثم انسخ الرابط (مثل `https://xxx-3000.app.github.dev`).
4. سجّل الدخول بحساب عميل تجريبي (مثلاً `01000000003` / `Demo!2026`، لم يستخدم كود الخصم بعد) أو أنشئ حساباً جديداً.
5. جرّب: تصفّح ← اختر لوناً ومقاساً ← أضف للسلة ← كود `WELCOME10` ← أتمم الطلب.
   ثم من تطبيق الإدارة (أو Swagger) أكّد الطلب واشحنه، وتابع الحالة تتغير في تطبيق العملاء.
6. **الإشعارات:** كل تغيير في الطلب يظهر في أيقونة الجرس 🔔 أعلى الرئيسية (مع عدد غير المقروء)، والضغط عليه يفتح الطلب.
7. **الدفع بالبطاقة (تجريبي):** اختر **بطاقة** عند إتمام الطلب، فتُفتح صفحة دفع تجريبية في المتصفح.
   - اضغط "محاكاة رفض البطاقة": يبقى الطلب غير مدفوع، ويظهر في صفحته زر "ادفع الآن".
   - أو اضغط "ادفع الآن": يُسجَّل الدفع ويُؤكَّد الطلب تلقائياً، ويصلك إشعاران.

   زر "العودة إلى التطبيق" يرجعك للطلب. افتح الطلب في تطبيق الإدارة ← "القيود المحاسبية" لترى قيد الدفع.
   لا يُخصم أي مبلغ حقيقي؛ ربط Paymob الحقيقي في [DEPLOY.md](DEPLOY.md).

## تجربة تطبيق الإدارة (أندرويد)

1. حمّل `dejavu-admin-debug-apk` من نفس صفحة **Artifacts** وثبّته (يمكن تثبيته بجانب تطبيق العملاء).
2. من شاشة الدخول اضغط **إعدادات الخادم** واكتب نفس رابط الخادم.
3. ادخل بأحد حسابات الموظفين أعلاه. كل دور يرى التبويبات والأزرار المسموحة له فقط:
   - `admin@dejavu.local` يرى كل شيء.
   - `store@dejavu.local` يرى المخزون فقط، و`sales@dejavu.local` يرى الطلبات والعملاء.
4. جولة مقترحة:
   - **الرئيسية:** مبيعات اليوم، أرباح الشهر، النقدية، والتنبيهات (طلبات بانتظار التأكيد، مرتجعات، نواقص، تحصيل لم يُورَّد).
   - **الطلبات:** افتح طلباً قيد الانتظار ← تأكيد ← تجهيز ← تسليم لشركة الشحن (الشركة ورقم التتبع) ← تم التسليم.
     افتح "القيود المحاسبية" أسفل الطلب لترى أثر كل خطوة.
   - **المزيد ← توريدات الشحن:** اختر الشحنات المسلّمة ← العمولة ← تسجيل التوريد إلى البنك.
   - **المزيد ← المرتجعات:** موافقة ← استلام (مع تحديد هل القطعة صالحة للبيع) ← استرداد.
   - **المخزون:** الأرصدة والنواقص، وتسوية كمية صنف بسبب.
   - **المزيد ← المشتريات / المصروفات:** استلام أمر شراء وسداد المورد، واعتماد مصروف وسداده.
   - **المزيد ← التقارير:** الأرباح والخسائر، المركز المالي (يجب أن يظهر "متوازنة")، والمبيعات حسب المنتج.

تفاصيل أكثر في [android/README.md](../android/README.md).
