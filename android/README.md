# تطبيقات Dejavu لأندرويد

مشروع Gradle واحد متعدد الوحدات يحتوي تطبيقين يتشاركان نفس الوحدات:
**تطبيق العملاء** (`app-customer`) و**تطبيق الإدارة** (`app-admin`).

```
android/
├── core/model      نماذج بيانات الـ API (Kotlin خالص)
├── core/network    عميل Retrofit + التوكن (تجديد تلقائي مرة واحدة عند 401) + تغيير الخادم أثناء التشغيل
├── core/data       مستودعات العميل (الجلسة، الكتالوج، السلة، العناوين، الطلبات، المرتجعات) + ترجمة رسائل الخادم
├── core/admin      نماذج ومستودعات الإدارة + أسماء الصلاحيات (Kotlin خالص)
├── core/ui         الثيم والمكوّنات المشتركة وتخزين التوكن المشفّر
├── app-customer    تطبيق العملاء (Jetpack Compose، عربي من اليمين لليسار)
└── app-admin       تطبيق الإدارة
```

## التقنيات

Kotlin 2.2 · Jetpack Compose (Material 3) · Navigation Compose · ViewModel + StateFlow ·
Retrofit + OkHttp + kotlinx.serialization · Coil 3 · Android Keystore لتشفير التوكن · minSdk 26 / targetSdk 36.

الاعتماديات تُربط يدوياً في `AppContainer` (عددها صغير ولا يحتاج إطار DI). يمكن الانتقال إلى Hilt لاحقاً عند نمو التطبيق.

## الشاشات

| الشاشة | ما تفعله |
|---|---|
| الرئيسية | بحث، الأقسام، مختارات Dejavu، وصل حديثاً |
| الأقسام / المنتجات | شجرة الأقسام، شبكة منتجات بالبحث والترتيب والتحميل التدريجي |
| المنتج | معرض صور، اختيار اللون ثم المقاس، التوفر الفعلي، الكمية، أضف إلى السلة |
| السلة | تعديل الكميات، كود الخصم، مشاكل المخزون، تقدير الشحن لعنوانك الافتراضي |
| إتمام الطلب | اختيار/إضافة عنوان، طريقة الدفع، ملاحظات، ملخص، تأكيد |
| طلباتي | القائمة، التفاصيل مع خط زمني للحالة، تتبع الشحن، الإلغاء، طلب الإرجاع |
| حسابي | الملف، العناوين (اختيار المحافظة من مناطق التوصيل فقط)، طلبات الإرجاع، الخادم، الخروج |

**الدفع:** الدفع عند الاستلام، وإنستاباي/المحفظة/التحويل البنكي (يؤكدها الفريق يدوياً).
الدفع بالبطاقة ينتظر ربط بوابة الدفع (المرحلة 5).

## تطبيق الإدارة (app-admin)

دخول الموظفين بالبريد وكلمة المرور. **التبويبات والأزرار تظهر حسب صلاحيات المستخدم**
(نفس صلاحيات الخادم، فلا يظهر زر سيرفضه الخادم).

| الشاشة | ما تفعله |
|---|---|
| الرئيسية | مبيعات اليوم، صافي ربح الشهر، النقدية والبنوك، المستحقات والالتزامات، تنبيهات قابلة للضغط |
| الطلبات | فلترة بالحالة وبحث، تغيير الحالة خطوة بخطوة (مع شركة الشحن ورقم التتبع)، تسجيل دفعة، استرداد، القيود المحاسبية |
| المرتجعات | موافقة / رفض، استلام مع تحديد القطع الصالحة لإعادة البيع، الاسترداد |
| المخزون | الأرصدة لكل مخزن، النواقص، تسوية الكمية بسبب |
| المنتجات | السعر وسعر ما قبل الخصم، النشر والإخفاء، التمييز في الرئيسية، مخزون وتكلفة كل مقاس |
| المشتريات | أرصدة الموردين، أوامر الشراء، الاستلام الجزئي، سداد المورد |
| المصروفات | تسجيل، اعتماد، سداد، إلغاء |
| توريدات الشحن | الشحنات المسلّمة التي لم يورّد تحصيلها، توريد مجموعة منها مع خصم العمولة |
| التقارير | الأرباح والخسائر، المركز المالي، المبيعات حسب المنتج / القسم / اليوم |
| العملاء | بحث، الرصيد المحاسبي، إجمالي المشتريات، آخر الطلبات |

## الحصول على التطبيق (APK)

كل رفع للكود يبني **APK تجريبي** تلقائياً على GitHub Actions:
1. افتح تبويب **Actions** في المستودع ← آخر تشغيل لـ **Android**.
2. انزل إلى **Artifacts** ← حمّل `dejavu-customer-debug-apk` أو `dejavu-admin-debug-apk` (ملف zip بداخله الـ APK).
3. انقله للموبايل وثبّته (اسمح بالتثبيت من مصادر غير معروفة).

## ربط التطبيق بالخادم

تطبيق العملاء: **حسابي ← الخادم**. تطبيق الإدارة: **إعدادات الخادم** في شاشة الدخول أو **المزيد ← الخادم**.
ثم اكتب الرابط واضغط "حفظ واختبار".

| أين يعمل الخادم | الرابط |
|---|---|
| على نفس الكمبيوتر مع محاكي أندرويد | `http://10.0.2.2:3000` (الافتراضي) |
| GitHub Codespaces | رابط المنفذ 3000 من تبويب PORTS، **بعد جعله Public** (زر يمين ← Port Visibility ← Public) |
| خادم على الإنترنت | `https://your-server.com` |

يمكن أيضاً تغيير الافتراضي وقت البناء: `./gradlew assembleDebug -Pdejavu.apiBaseUrl=https://your-server/api/v1/`

النسخة التجريبية (debug) تسمح بـ `http`. نسخة الإنتاج (release) تقبل `https` فقط.

## البناء محلياً

```bash
cd android
./gradlew :app-customer:assembleDebug :app-admin:assembleDebug   # يحتاج Android SDK (Android Studio يثبته تلقائياً)
./gradlew -PjvmOnly=true test                  # الوحدات المشتركة فقط، بدون Android SDK

# اختبارات العقد مع خادم يعمل ببيانات تجريبية:
DEJAVU_API_URL=http://localhost:3000/api/v1/ ./gradlew -PjvmOnly=true :core:data:test :core:admin:test
```

أو افتح مجلد `android/` في Android Studio وشغّل `app-customer` أو `app-admin`.

## الاختبارات

- **وحدات:** تنسيق المبالغ، تجديد التوكن (مرة واحدة لعدة طلبات متزامنة)، إنهاء الجلسة، تحليل أخطاء الخادم،
  تغيير الخادم، التحقق من المدخلات، ترجمة الرسائل.
- **عقد مع الخادم الحقيقي:** رحلة العميل كاملة (تسجيل ← عنوان ← سلة + كوبون ← طلب ← إلغاء ← خروج)،
  وقراءة كل طلبات ومرتجعات العميل التجريبي، ورحلة الموظف (تأكيد طلب ← شحن ← تسليم ← توريد التحصيل، وأعمال المخزون
  والمشتريات والمصروفات والتقارير) مع التأكد أن أمين المخزن لا يصل للطلبات. تعمل في CI ضد خادم ببيانات تجريبية، فأي اختلاف بين التطبيق والـ API يظهر فوراً.
