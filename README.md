# Dejavu — نظام محاسبي متكامل + تطبيقا أندرويد

نظام محاسبي ومتجر إلكتروني متكامل يتكون من:

1. **الخادم (Backend API)** — NestJS + PostgreSQL + Prisma: المصدر الوحيد للبيانات والمحاسبة.
2. **تطبيق العملاء (أندرويد)** — تصفح المنتجات، السلة، الطلب، الدفع (عند الاستلام أو بالبطاقة)، تتبع الطلبات، الإشعارات، المرتجعات.
3. **تطبيق الإدارة (أندرويد)** — إدارة المنتجات والمخزون والطلبات والمشتريات والمصروفات، القيود والتقارير المالية، والمستخدمين والصلاحيات.

## 🚀 جرّب النظام الآن

افتح المستودع في **GitHub Codespaces** (زر Code ← Codespaces) أو شغّل `docker compose up --build`،
ثم افتح صفحة Swagger التفاعلية. التفاصيل والحسابات التجريبية وجولة مقترحة: **[docs/TRY_IT.md](docs/TRY_IT.md)**

## هيكل المستودع

```
backend/
  prisma/
    schema.prisma        هيكل قاعدة البيانات الكامل
    migrations/          الـ migrations (الجداول + قواعد السلامة المحاسبية)
    seed.ts              دليل الحسابات، الأدوار والصلاحيات، السنة المالية، الإعدادات
  src/                 الـ API (NestJS)
  test/                اختبارات e2e
android/                 تطبيقا العملاء والإدارة (Kotlin + Compose) والوحدات المشتركة
deploy/                  التشغيل على خادم خاص: Docker Compose + Caddy (HTTPS) + نسخ احتياطي
docs/
docker-compose.yml       PostgreSQL + Redis + الـ API ببيانات تجريبية
render.yaml              نشر بضغطة واحدة على Render
.devcontainer/           إعداد GitHub Codespaces
```

## التشغيل محلياً

```bash
docker compose up -d                # PostgreSQL 16 + Redis
cd backend
cp .env.example .env
npm install
npm run db:deploy                   # إنشاء الجداول + Triggers + Views
npm run db:seed                     # البيانات الأساسية
npm run start:dev                   # http://localhost:3000/api/v1 — التوثيق على /docs
npm run test:e2e                    # الاختبارات الشاملة
```

المستخدم الافتراضي للإدارة: `admin@dejavu.local` / `ChangeMe!2026`
(يمكن تغييره عبر `SEED_ADMIN_EMAIL` و `SEED_ADMIN_PASSWORD` — **غيّره فوراً في الإنتاج**).
